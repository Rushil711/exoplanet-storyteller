      A planetarium desk for real worlds

      Pick a planet. Hear only what the archive can stand behind.

      Gemma, running locally, writes a short story from one planet’s NASA record. A verifier then checks every number, unit, spectral type and claim. If the story can’t be grounded, you get one built straight from the data instead — and you can see the score either way.

      Data: the NASA Exoplanet Archive, composite planet table pscomppars. Star color is estimated from st_teff because spectral type is missing for most planets. Stories never invent an atmosphere, water, or life.
